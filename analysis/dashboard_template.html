그룹별 연락 시뮬레이터

연락하면 몇 %가 다시 사는지, 연락 1명당 비용이 얼마인지 바꿔보면 어느 그룹이 남는지 볼 수 있음

추가 매출 = 고객 수 x 추가 재구매 비율 x 평균 금액, 순효과 = 추가 매출 - 연락 비용. 비율은 가정이며 비율을 바꿔도 우수 그룹이 일반 그룹보다 먼저임
